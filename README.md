# 📖 C How to Program - Book Exercises & Solutions

Bu depo, **Deitel & Deitel** tarafından yazılan **"C How to Program"** kitabı üzerinden C dilini çalışırken çözdüğüm alıştırmaları, bölüm örneklerini ve pratik kodları içermektedir.

## 📂 İçerik ve Örnek Çalışmalar

Depo içerisinde kitabın farklı bölümlerine ait pek çok algoritmik uygulama ve problem çözümü yer almaktadır:
- **Temel Matematiksel Hesaplamalar:** Pi sayısı hesaplama (`calculating value of pi`), üslü sayılar (`compute e^x`), Armstrong sayıları (`armstrong number`)
- **Finansal ve Pratik Uygulamalar:** Kredi limiti hesaplama (`calculating credit limit`), bileşik faiz (`compound interest calculations`), haftalık maaş hesaplama (`calculating weekly pay`)
- **Döngüler ve Desenler:** Çubuk grafik yazdırma (`bar chart printing program`), yıldızlarla desen oluşturma (`checkerboard pattern of asterisks`)
- **Veri Yapıları:** Diziler (`array 1`) ve ASCII değerleri (`ascii values`) üzerine çalışmalar.
